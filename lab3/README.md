# Лабораторная работа № 3. Коллекция минералов

В центре сцены расположен один многогранник из второй лабораторной. При запуске на него наложена керамическая мозаика.

## Запуск в Visual Studio 2022

1. Распакуйте архив целиком. Папку lab3 можно положить рядом с lab2.
2. Откройте Visual Studio → Файл → Открыть → Папка. Выберите lab3, где лежит CMakeLists.txt.
3. Выберите конфигурацию msvc-debug. При первом открытии CMake скачивает зависимости через Git. Нужны доступ к GitHub, Vulkan SDK с glslc и компонент Visual Studio «Разработка классических приложений на C++» с CMake.
4. Выберите целью запуска vulkan-starter-app.exe и нажмите Ctrl+F5. При переносе папки на другой компьютер выполните настройку CMake заново.

## Демонстрация

1. В списке **Texture** выберите Ceramic mosaic, Blue agate или Hammered copper.
2. Включите **Tidal bands** и сравните узор до и после включения эффекта на этой же фигуре.

## Как это устроено

- PNG загружаются через stb_image. Вершины, индексы и изображения передаются в память устройства через staging-буферы.
- Материалы имеют собственные наборы дескрипторов. В каждом наборе привязаны общий динамический uniform-буфер и одна текстура основного цвета. Смещение для конкретной модели кратно minUniformBufferOffsetAlignment.
- Фрагментный шейдер смещает первую пару UV синусоидой, берёт вторую выборку той же текстуры с поворотом и масштабированием, смешивает цвета и меняет оттенок по фазе волны. Время и флаг эффекта передаются через push-константы перед рисованием многогранника.
